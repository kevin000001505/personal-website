  • Built 20+ concurrent Prefect flows ingesting NOAA SWPC feeds and OpenSky state vectors with automated retry, failover, and proactive policies for stuck runs.

Storage & Query Performance
  • Migrated production PostgreSQL → TimescaleDB without downtime — hypertable compression cut storage 70% while preserving full SQL compatibility.
  • Tuned shared_buffers, work_mem, WAL & checkpoint behavior + rebuilt index strategy (chunk-aware, partial, functional) for 40% query gains.
  • Designed PostGIS flight-path pipeline with lateral joins, GiST indexes, and partition pruning for sub-second spatial queries.

  • Added a Redis caching layer on hot endpoints, cutting API response times 80% by eliminating redundant DB hits.
  • Moved alerting logic into PostgreSQL stored procedures & views for 70% lower alert latency (0.1 ms → 0.03 ms).
